Contact

SecureChat is run as an open-source project, so all contact goes through its public GitHub repository. There is no support email, and we never ask for your personal details.

Questions, bugs and ideas

Open an issue at github.com/0x0806/securechat/issues. Describe what you did, what you expected and what happened instead, plus your browser and device. Please do not include screenshots of other people's chats.

Security problems

Report vulnerabilities privately through GitHub's private vulnerability reporting, never in a public issue. The security policy explains scope and response times, and the machine-readable contact is at /.well-known/security.txt.

Abuse during a chat

If someone breaks the rules, use Report in the chat. It ends the conversation immediately and stops you being matched with that person again. There are no moderators who can review chats, because chats are never stored. If you are in danger, contact your local emergency services.

Contributing

Pull requests are welcome. The README explains how to run the app and its tests locally.
